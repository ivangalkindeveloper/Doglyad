# runpod-gpu — видеокарты для эндпоинтов RunPod

Поле `gpuTypeIds` в `backend/main/config/runpod_endpoints.json` определяет, на каком железе поднимется воркер. Ошибка здесь не ловится ни линтером, ни `runpod-plan` — она проявляется падением воркера в проде. Этот skill сверяет конфиг с живым списком RunPod.

Подробности по всем настройкам конфига — в [`RUNPOD.md`](../../../backend/main/RUNPOD.md).

## Откуда берётся список

Публичный GraphQL RunPod, **ключ не нужен**:

```bash
curl -s -X POST https://api.runpod.io/graphql \
  -H "Content-Type: application/json" \
  -d '{"query":"query { gpuTypes { id displayName memoryInGb } }"}'
```

Это единственный полный источник — 48 типов с VRAM. Не используй вместо него:

- **REST API** — ручки по GPU там нет вообще (см. `https://rest.runpod.io/v1/openapi.json`).
- **`docs.runpod.io/references/gpu-types`** — таблица неполная, в ней **нет MIG-вариантов**. Именно из-за этого в конфиг когда-то не попали Blackwell-слайсы, и воркер упал.
- **enum'ы внутри `openapi.json`** — их два и они расходятся: в `GPUTypeId` нет Blackwell и H200, в `EndpointCreateInput.gpuTypeIds` нет MIG.

## Как пользоваться

```bash
# проверить текущий конфиг
python3 .claude/skills/runpod-gpu/scripts/gpu_types.py check

# посмотреть доступные карты (опционально с фильтром по памяти)
python3 .claude/skills/runpod-gpu/scripts/gpu_types.py list --min-vram 40
```

Скрипт работает любым `python3` без зависимостей: при отсутствии CA-сертификатов сам переключается с `urllib` на `curl`. Код возврата `check`: `0` — чисто, `1` — есть проблемы.

Отметки в выводе:

| | Значение |
|---|---|
| `ok` | id существует, памяти хватает с запасом |
| `!` | впритык по памяти, либо архитектура новее Hopper |
| `✗` | id не существует, память не хватит, либо `gpuTypeIds` вовсе не задан |

## Что проверяется

1. **Существование id.** Строки должны совпадать точно: `NVIDIA L4`, а не `L4` или `NVIDIA L4 24GB`.
2. **VRAM под модель.** Размер весов оценивается по числу параметров в id модели (`medgemma-27b-it` → 27B) с поправкой на `QUANTIZATION`: bf16 — 2 байта на параметр, `fp8` — 1, `awq`/`gptq` — 0.5. Дальше сверяется с `VRAM × GPU_MEMORY_UTILIZATION`. Нужен запас минимум ~6 ГБ на активации профилировки и KV-кэш.
3. **Архитектура.** Карты новее Hopper (Blackwell — `sm_120`: RTX PRO *, B200, B300, RTX 5080/5090) помечаются предупреждением: PyTorch внутри образа собран под конкретный набор compute capability, и на незнакомой карте воркер падает с `no kernel image is available for execution on the device` ещё до загрузки весов.
4. **Наличие списка.** Пустой `gpuTypeIds` — отдельная проблема: RunPod выдаст произвольную карту, включая MIG-слайсы, которых нет в публичной документации.

## Как обновлять конфиг

Скрипт **только сообщает** — правки в `runpod_endpoints.json` вноси сам через Edit, после согласования с пользователем.

1. Прогони `check`.
2. Если нашлись проблемы — покажи их пользователю и предложи конкретную замену. Кандидатов бери из `list --min-vram N`, где `N` — требуемый минимум из отчёта.
3. Порядок в списке — это приоритет: RunPod берёт первую доступную карту. Ставь первой ту, что дешевле или быстрее по задаче, дальше — запасные того же или большего объёма.
4. Не добавляй Blackwell-карты, пока не подтверждено, что образ из `imageName` их поддерживает.
5. После правки прогони `check` ещё раз — он должен вернуть `0`.

Изменение `gpuTypeIds` применяется к RunPod через `make runpod-plan` → `make runpod-apply` (skill не делает этого сам).

## Полезно знать

- Модели MedGemma — bf16, веса примерно `2 байта × число параметров`: 4B ≈ 8 ГБ, 27B ≈ 54 ГБ. Для 4B подтверждено логом воркера: `Checkpoint size: 8.01 GiB`.
- `TENSOR_PARALLEL_SIZE` должен совпадать с `gpuCount`. Скрипт считает память **на одну карту**, поэтому при `gpuCount > 1` его вывод по большим моделям будет пессимистичным.
- Список карт у RunPod меняется — не кэшируй его и не переноси в конфиг проекта, ходи за ним каждый раз.
- Если у модели нестандартное имя и число параметров из него не вытаскивается, скрипт напишет «размер весов не распознан» и проверит только существование id. Тогда прикинь память вручную.
